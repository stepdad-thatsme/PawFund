# PawFund
🐾 PawFund – A Simulated Donation Platform for Dogs in Need PawFund is a front-end web project that demonstrates how empathy, storytelling, and interactive design can inspire compassion through technology. Modeled after platforms like GoFundMe, PawFund allows users to explore simulated donation campaigns for dogs suffering from various illnesses.
